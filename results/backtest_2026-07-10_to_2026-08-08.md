## Bugs found and fixed this session, now reflected in the pipeline this
## backtest exercised

- `combo_player_ids` dropped at two persistence boundaries (`write_json`,
  `persist_player_snapshots`) — every real `combined_strikeouts` pick would have
  failed grading the next morning.
- `value_board.py` never called `quality_control()` — the board that actually
  gets bet was bypassing the opener/lineup-trust safety layer entirely.
- `grade_value.py`'s `settle()` used `act.get(stat, 0) >= needs`, silently
  scoring every bet on an untracked stat (runs/rbis/doubles/triples/
  stolen_bases/hits_runs_rbis) as a guaranteed loss instead of skipping it.
- `value_board.py`'s `screen()` accepted `reject_suspect` but never read it —
  the CLI's `--allow-suspect` flag was a silent no-op.
- `grade_results.py`'s hard_hit branch always passed `row=None` to
  `opportunity_context`, marking every hard_hit pick "did not appear" — found
  directly from this backtest's own coverage report (`n_fair` exactly 0 on
  5,914 rows).
- Missing HTML boards/parlay examples in the daily commit + artifact steps
  (`mlb-daily.yml`) — every production run had been computing them and
  discarding them.

All fixed, tested (full `test_*.py` suite green), and pushed to
`claude/gridiron-continuation-dvaljm`; CI green on every commit.
