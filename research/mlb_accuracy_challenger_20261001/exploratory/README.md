# Exploratory evidence (Phase A/B): NOT confirmatory

Both scripts read 2026 regular-season outcomes that PR #201, #217 and #219 had already examined. They inform the hypotheses in the preregistration. They are not evidence for any challenger.

## `reproduce_219_independent.py` (Phase A)
A reimplementation that does not import #219's code. It rebuilds the #219 dataset at data snapshot `58abe9f2e5` and reruns its weekly forward chain. Output: `reproduce_219_independent.out`.

| Quantity | Value |
|---|---|
| Rows | 3,984 (1,400 frozen-board, 2,738 final-board, 154 in both) |
| Out-of-sample rows | 3,141 |
| Games | 207 |
| Price-only recalibration − raw model (log loss) | −0.008222 |
| Model + price − price-only (log loss) | +0.000612 |
| Top Picks | 75; stated 0.6416; realized 0.5333 |

All of these equal #219's `report.json`. Separately, all four #219 scripts were rerun at #219's head `68fa5d0638`, and every committed report regenerated byte-identically.

The script's absolute paths point at a checkout of #219's branch. It is kept here as provenance.

## `diagnosis_equal_volume.py` (Phase B)
Runs on the same out-of-sample rows (written to a scratch file by the script above). It compares selectors at **equal volume** (N_d = champion Top Picks per slate, 75 picks over 23 slates) and checks portfolio concentration and residual-signal stability. Output: `diagnosis_equal_volume.out`.

## `diagnosis_equal_volume_band040_070.py`
The same comparison, but only over candidates whose posted implied probability lies in the preregistered band 0.40–0.70. Output: `diagnosis_equal_volume_band040_070.out`.

This run informed the preregistration's choice of C2 (the residual selector) as the primary challenger:

| Arm | Hit rate | Mean posted price | ROI |
|---|---|---|---|
| Residual selector (C2) | 46/75 = 0.613 | 0.561 | +10.6% |
| Champion | 0.533 | 0.549 | −2.7% |

n=75 is far too small to conclude anything, and the 95% CIs overlap heavily.
