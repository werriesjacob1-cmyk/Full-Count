# FC-OPS-002: inactive prospective-evaluation bridge

This branch is stacked on draft PR #234 (`6036d29c502d0bfcc6f8efe101aabca89c880c07`) solely to import its strict FanDuel parser. The separately unmerged contracts inspected for this bridge are #226 (`99dec6f71f56ba2d6010aac0aff6ae1404245172`), #230 (`5c25eb1ecc1ebb594cc266447b35b331f4e96499`), and #235 (`84b294fc4d74409c9f5ef2bdde57aeb369fae075`, stacked on #233 `c3f3362d67da823ee492ad361017e1e2a4a065a9`). These exact revisions are research dependencies, not merge authority.

`build_ledger` is an offline pure function. It checks the S1 and dashboard record hashes, capture hash and chronology, archived root and page bytes, strict #234 offers, exact S1 offer identity, policy decision identity, original uncapped champion N, exact final publication-manifest hash and staged candidate IDs, and the frozen #235 model artifact SHA-256. It never fetches a quote or changes a dashboard decision. Total-bases 2+ challenger probabilities use the stored M2 transform, including medians, missing indicators, standardization and coefficients, without refitting. Feature snapshot bytes must match their digest and input values. This is byte integrity, **not** independent proof that the features were calculated from pregame baseball source records.

The three research arms are the exact intended champion IDs, a fixed market-only raw break-even ranking, and a frozen-model expected-return ranking across eligible existing markets and 2+ total bases. Replacement rows additionally need a hash-bound pregame policy snapshot proving the 0.60 Top Pick floor, A/B evidence, confirmed lineup, freshness, nonzero sample and the existing robust value gate. Missing policy evidence rejects the replacement. Alternative arms use a fixed limit of one wager per player and two per game. Game/player clusters and shortfalls are recorded. A zero-pick champion creates zero choices in all arms. Incomplete discovery, missing quotes, identity/timing failures and unmatched N make the unit non-comparable. The candidate universe is limited to #226 S1 freeze candidates; **it is not a full sportsbook opportunity census**. Cross-market M2 uncertainty and the risk of selecting expensive favorites are not validated by this fixture. PR #236 reports that frozen 2+ TB almost never clears the Top Pick floor; its value-lane versus hits-priority governance choice remains open. The synthetic TB replacement is a structural test, not an estimate of operational volume.

`evaluate_external_grades` can link separately supplied, hash-bound grade records and compute win/loss/void/push counts and flat-stake net/ROI only when an arm is complete. It rejects identity changes and requires an explicit book-rule reference for void/push. It does not certify the truth of an external grade or its settlement rules. A linked record is always marked `grade_truth_independently_verified: false`; no synthetic return is a betting result.

Every ledger is `SYNTHETIC_CONTRACT` or `ARCHIVED_OBSERVATIONAL`, `research_only: true`, and `prospective_certified: false`. `write_once` creates a local hash-sealed file and rejects conflicting bytes. That local seal does not supply an independent external anchor, recoverable chain, public exposure proof or long-term retention. The #230 export describes intended dashboard decisions, not confirmed publication. There is no shared verified run ID between #230 and #226, and this bridge does not execute their upstream raw schedule, lineup, board-freeze, export or external-anchor verifiers. Therefore an archived structurally matched unit is **not** a prospectively authenticated same-run slate.

The synthetic fixture in `test_fc_ops_002_bridge.py` demonstrates two-player, one-game replay. It deliberately has no real quote or outcome. Focused tests cover closed/suspended/inactive offers, response hash mutation, identity and line changes, stale and late timing, incomplete binding, lineup assumption, starter issue, unavailable 2+ TB, insufficient N, duplicate candidate, unsupported book/push line, missing or late features, write-once conflict and separate grade linkage. The exact #235 model file was independently hashed and its 49-feature median-vector score reproduced numerically; no authentic feature snapshot was available for an operational replay.

Before any forward experiment, an independent integrator must deliver one run-bound bundle containing the actual pre-withholding dashboard export, S1 complete source archive and authenticated game/roster coverage, publication manifest and exposure linkage, the frozen feature vectors derivable from pregame inputs, explicit book-specific settlement rules, and durable externally anchored retention. The arms must be frozen before games and graded from independent outcomes. Until then, this branch supports contract testing only. No production scoring, capture, workflow, publication or public evidence was changed.
